关于

数据、实现与许可。

为什么会有这个项目

原「诗鲸」App 已于 2020 年后停止维护，作者注销了账号与官网，源码不可得。 官方 APK 被腾讯乐固加固，静态反编译只能拿到壳。但加固只保护代码，不保护数据与资源 —— 于是选择用开源数据加恢复出的界面资源重写一份。

数据来源

诗词数据来自开源项目 libpoetry/poetry-1 （原 javayhu/poetry 的 fork），2017 年整理自古诗文网， 共 72,417 首诗词、3,154 位诗人。译文与赏析覆盖约 8%，这是数据源本身的情况。

开源许可

本项目以 GPL-3.0 发布，与诗词数据的许可保持一致。原 App 的名称与图标版权归原作者， 不在本许可覆盖范围内。

技术实现

原生 Kotlin + XML 布局，仅依赖 AndroidX 与 Material，无第三方 SDK。 数据分两层：索引与热门正文随包分发，冷门详情按 1,000 首一片的粒度从 jsDelivr 按需拉取。构建全程在 GitHub Actions 完成。
