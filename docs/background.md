# 背景：这个项目是怎么来的

## 原 App 的处境

「诗鲸」（包名 `me.javayhu.poetry`）是一款古诗词学习应用，最后一版是 **v4.0.1（versionCode 91）**，
构建于 2020 年 4 月，targetSdk 29。作者已注销 GitHub 账号与官方网站，应用停止维护，
**源码不可得**。官方 APK 至今仍能在网上找到，但它的联网功能早已失效 ——
原版后端用的是 LeanCloud，随作者注销一并下线。

## 为什么不是直接反编译改源码

官方 APK 被 **腾讯乐固（Tencent Legu）** 加固，证据确凿：

- `classes.dex` 仅 72 KB / 17 个类，全是壳类：`com.tencent.StubShell.TxAppEntry`、
  `com.wrapper.proxyapplication.*`、`me.javayhu.poetry.MyWrapperProxyApplication`
- `assets/0OO00l111l1l`（3.8 MB，熵值 7.89）存放加密后的真实 dex，里面没有任何明文残留
- `lib/{armeabi,armeabi-v7a}/libshell-super.2019.so`，其编译信息直指腾讯内部项目
  `git.code.oa.com/SecurityResearchProject/ANTI-Reverse.git`

静态反编译只能得到壳。要拿到真实代码必须用 Root 设备 + FART/frida-dexdump 动态脱壳，
脱壳产物仍是混淆代码，维护成本远高于重写。此外该 APK 的 `.so` 只有 32 位
（armeabi / armeabi-v7a，无 arm64-v8a），在纯 64 位设备上根本无法安装。

**但这并不意味着无从下手** —— 加固只保护代码，不保护数据与资源：

| 层面 | 能否恢复 | 说明 |
|---|---|---|
| 数据层 | ✅ | 作者的数据仓库仍在（见下） |
| UI 资源层 | ✅ | 166 个布局、291 张图、完整配色与文案全部明文 |
| 功能结构 | ✅ | 从 AndroidManifest 可读取出 21 个 Activity 与 7 个微件 |
| Java/Kotlin 源码 | ❌ | 被乐固加固，需动态脱壳 |
| 服务端 | ❌ | LeanCloud 已下线 |

于是选择了**重写**：用开源数据 + 恢复出的界面资源，做一个纯离线的原生应用。

## 数据从哪来

诗词数据来自 [`libpoetry/poetry-1`](https://github.com/libpoetry/poetry-1) ——
它是原 `javayhu/poetry` 的 fork，**GPL-3.0** 许可，也就是诗鲸官方的配套数据库，
2017 年整理自古诗文网：

- **72,417 首**诗词（正文 / 译文 / 赏析 / 创作背景 / 标签）
- **3,154 位**诗人（简介 / 生平 / 头像 URL）
- 45 个分类标签
- 名句 5,764 条（从官方 APK 内提取）

> 数据说明：译文与赏析只覆盖约 8% 的诗词，这是原数据源（古诗文网）本身的情况，
> 官方 App 当年也是如此。

## 界面资源从哪来

用 apktool 反编译官方 APK，从明文资源中取出并复用：

- **配色**：原版的鲸鱼蓝色阶（`#E1F5FE` → `#01579B`，主色 `#03A9F4`）
- **图标**：星标、云同步、搜索、筛选等矢量图标
- **微件预览图**：默认 / 多行 / 浅色 / 深色 / 定制 / 整点 / 每日 共 7 张
- **文案**：与原版一致的措辞（如「作品 %d 首」「定制微件」）
- **微件参数**：刷新周期、最小尺寸、是否支持锁屏，均取自原版配置

## 数据分层设计

为了兼顾「安装包小」与「数据全」，数据分两层：

```
                        72,417 首诗 / 3,154 位诗人 / 5,764 条名句
                                     │
              ┌──────────────────────┴──────────────────────┐
              ▼                                             ▼
     随 APK 打包（约 2.6 MB）                    云端按需（约 34 MB）
     · 全部诗词索引        · 名句                · 诗词详情 74 片（每片 1000 首）
     · 诗人索引            · 标签反向索引        · 诗人详情 11 片（每片 300 位）
     · 热门 Top5000 正文
```

列表、搜索、筛选、名句、专题**全部离线可用**；只有冷门诗词的详情需要联网，
每个分片约 0.4 MB、一次覆盖 1,000 首，下载后永久缓存。分片按 `poetryId` 区间切分，
客户端用 `id / 1000` 直接定位，不需要额外的索引表。

## 关于原版的其他部分

原版的账号体系与商业化部分（会员付费、打赏、小程序、公众号）没有复刻 ——
它们依赖的服务端已下线，且与「继续自己用这款 App」的目标无关。
收藏功能改用 **本地存储 + WebDAV 同步**：数据存在用户自己的网盘，
不需要任何后端，也不需要注册账号。
